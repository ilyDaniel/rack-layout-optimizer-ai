# Rack Layout Optimizer AI

An experimental project exploring **constraint programming and AI optimization techniques** for designing efficient data center rack layouts.

## Project Motivation

Modern data centers must balance multiple competing constraints including:

* compute performance
* power consumption
* thermal limits
* network bandwidth
* hardware placement rules

Designing optimal rack layouts manually is complex due to the huge number of possible configurations.

This project explores how **AI-based optimization methods** can automatically generate efficient layouts.

## Inspiration

This project was inspired by:

* Grid-based optimization mechanics in games where items are arranged for bonuses
* A university project involving **constraint programming for railway scheduling**

Both problems involve allocating limited resources while satisfying complex constraints.

## Project Goals

1. Model rack layout as a **constraint satisfaction problem**
2. Implement constraint solving using **Google OR-Tools**
3. Explore optimization algorithms such as:

   * Genetic Algorithms
   * Simulated Annealing
4. Experiment with **machine learning approaches using PyTorch**
5. Visualize generated rack layouts
